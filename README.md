# journal-to-ttyingqiu

这是一个用于归档和发布独立 HTML 页面的仓库。  
本仓库不针对任何特定网站或域名，仅作为若干静态页面的集合存储与展示空间。

## 项目简介

journal-to-ttyingqiu 旨在存放一系列独立编写的 HTML 文件。  
这些文件可能包含各类笔记、记录或文档形式的页面内容，彼此之间没有强关联，均作为独立页面存在。

仓库本身不包含后端服务或动态功能，所有页面均为静态 HTML，可直接通过浏览器访问。

## 目录说明

```
.
├── index.html          # 首页或目录索引（如有）
├── page-1.html         # 示例独立页面
├── page-2.html         # 示例独立页面
└── README.md           # 本文件
```

实际目录结构可能随归档内容的变化而调整。  
每个 HTML 文件通常代表一份独立的归档记录。

## 页面归档说明

- 所有页面均为纯静态 HTML，不依赖外部数据库或服务器端脚本。
- 页面之间无导航关联，可通过直接链接访问。
- 归档内容可能包含文字、图片、样式或脚本，但均内嵌或托管于仓库中。
- 不保证页面之间的样式或结构一致性。
